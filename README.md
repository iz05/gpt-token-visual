# GPT Token Visualization
Displays the embeddings of tokens as they travel through attention layers in nanoGPT. 
# Instructions
Clone the repository.
```
git clone https://github.com/iz05/gpt-token-visual.git
```
Open a terminal. Ensure you are in the correct directory.
```
cd gpt-token-visual
```
Download dependencies
```
pip install -r requirements.txt
```
Download the file from [here](https://www.dropbox.com/scl/fi/ocaovecmf7che47p1pn0o/ckpt.pt?rlkey=lpfz7b1e5k26ypuw6gltocxub&st=mt9nen3h&dl=0) and move it into the directory.
To view the website on your local server, run
```
python app.py
```
